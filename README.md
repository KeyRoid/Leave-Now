# Yoyu

Yoyu is a simple departure timing utility.

Set your target time, travel time, and buffer once. Yoyu then shows whether you still have time, should hurry, or are past your departure limit.

Yoyu is intended as a paid, one-time purchase utility. It does not use subscriptions, in-app purchases, advertising, accounts, location tracking, or route search.
